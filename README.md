# REALITYコメント

わんコメ用プラグインです。REALITYの公式コメント画面と同じ接続でコメントを受け取り、選んだ枠へ流します。コインの合計も、ユーザー別・配信ごと・日ごとに残します。

バージョン 1.0.0。REALITY公式、わんコメ公式の機能ではありません。

## 必要なもの

- わんコメ
- 配信中に REALITY ドックの「コメント」で開くページ

コメントURLは配信のたびに変わります。プロフィールURLからは取れないので、配信ごとに貼り付けてください。

無料版のわんコメでは、コメントへのクレジット表記が必要です。

## 置き場所

このフォルダを次の場所に置きます。フォルダ名はそのままで構いません。

```
%APPDATA%\onecomme\plugins\reality-comments
```

わんコメでプラグインを有効にし、再読み込みします。設定ページはプラグイン一覧から開きます。

## 設定

1. コメントURLに、`https://reality.app/comments/配信ID.ハッシュ` を貼る（REALITY OBS Pluginのコメント表示機能を使う。）
2. 取り込み先の枠を選ぶ
3. 「保存して接続」を押す

通常コメントと配信者コメントは常に取り込みます。それ以外はチェックで選べます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| ギフト | オン | コインギフトを枠へ流す |
| いいね | オフ | 行の背景を薄い黄にする |
| 入室 | オフ | 行の背景を薄い青にする |
| フォロー | オフ | フォロー通知 |
| シェア | オフ | シェア通知 |
| システムメッセージ | オン | 配信時間の経過など |
| 接続時の既存コメント | オフ | つないだ時点で画面に出ているコメントも取り込む |

読み上げは、選んだ枠の読み上げ設定に従います。枠は有効にしてください。

接続がすぐ切れたときは、15秒から始めて最大60秒まで間隔を空けて再接続します。つながったまま45分たつと、接続を張り直します。

## コイン集計

ギフトのコイン数は、REALITYが渡す消費コインを使います。個数を掛けません。

ガチャチケは 0 コインです。コメントとしては残りますが、合計・回数・CSVには入りません。

ギフトの表示をオフにしていても、コインは数えます。接続前から画面に残っているギフトも数えます。配信を変えても、過去の記録は消えません。「この配信の集計を消す」は、いま接続している配信だけを消します。日付は日本時間です。

画面に出る合計は、いまの配信の分です。

## 書き出されるファイル

プラグインフォルダの中にできます。ギフトが入るたびに上書きされます。視聴者名が入るので、このリポジトリには含まれません。

| ファイル | 内容 |
| --- | --- |
| `coins.txt` | いまの配信の合計 |
| `users.txt` | いまの配信のユーザー別 |
| `export/reality-users.csv` | 全期間のユーザー別。最終行が総計 |
| `export/reality-by-stream.csv` | 配信ごと |
| `export/reality-by-day.csv` | 日ごと |
| `export/reality-gifts.csv` | ギフトの明細 |
| `export/streams/配信ID.csv` | その配信だけのユーザー別 |
| `export/days/YYYY-MM-DD.csv` | その日だけのユーザー別 |

設定ページのボタンは、同じCSVを手元にダウンロードするとき用です。

## 配信画面に合計を出す

OBSのブラウザソースに、次のURLを追加します。コメント用テンプレートとは別に追加してください。背景は透明です。

```
http://localhost:11180/plugins/com.reality.onecomme.comments/total.html
```

合計と、いまの配信のユーザー別ランキングを表示します。

## サポーターマーク

ランク1から9の画像は同梱していません。次のファイルを自分で用意し、`badges/` に置いてください。

| ファイル | サイズ |
| --- | --- |
| `supporter-1.png` 〜 `supporter-9.png` | 64×64 ピクセルの PNG |

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `plugin.js` | 設定、接続、わんコメへの送信、集計 |
| `socket.js` | コメントサーバへの接続 |
| `comment.js` | コメントの種類分けとコインの読み取り |
| `stats.js` | 集計とCSV |
| `index.html` | 設定ページ |
| `total.html` | 配信画面用の合計表示 |
| `badges/` | 自分で置くサポーターランク1〜9の画像（各 64×64） |
